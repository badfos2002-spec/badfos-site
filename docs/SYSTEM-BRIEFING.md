**התצוגה היא תלת-ממד אמיתי** — 14 דגמי GLB (22MB, דחוסים ב-meshopt), והעיצוב מוטבע כ-`Decal` על המודל. לכל מוצר יש `VARIANTS` ב-`components/designer/three/Tshirt3DModel.tsx` שמגדיר מיקום/גודל/עומק ההטלה לכל אזור.

**חיוני להבין:** `DecalGeometry` עובר על **כל** משולש ברשת בכל בנייה. יעד הדקאל בחולצה הוא **340,513 משולשים ≈ 248ms**. כל פיצ'ר שמשנה מיקום/גודל דקאל בזמן אמת חייב תצוגה מקדימה אימפרטיבית והטלה אחת בשחרור — אחרת 4fps.

## 8. מה נבנה לאחרונה (8-14.8.2026)

טכני: הסטה במערכת הצירים של המקרן (עובד זהה לכל 8 המוצרים כולל אזור `back` המסובב 180°) · תצוגה חיה אימפרטיבית על רשת הדקאל + הטלה אמיתית אחת בשחרור (434fps במקום 4) · **במובייל אין גרירה בכלל** — רק חצים וסרגל, לפי בקשת הבעלים.

**ניווט בוויז** — כפתור בכל הזמנת משלוח שפותח וויז עם הכתובת. אייקון כהה בכוונה (ניגודיות 9.5:1) כי הוא נלחץ בטלפון בשמש ליד הרכב.

**מתג עצירת הזמנות** — מתג on/off באדמין שעוצר הזמנות וחיובים. חסימה כפולה: לקוח + שרת (503). המצב יושב ב-Firestore `settings/orders`.

**דוח עלויות שבועי** — מדידת שימוש אוטומטית, מנויים קבועים שהבעלים מזין, ומייל שבועי שהמדד המרכזי בו הוא **עלות להזמנה**.

## 10. מלכודות שיעלו לך זמן אם לא תדע אותן

**`npm run lint` לא עובד.** אין `.eslintrc` בריפו; `next lint` נופל לפרומפט אינטראקטיבי ותוקע. **השערים האמיתיים:** `npx tsc --noEmit` + `npm run build`.

**`/admin/*` לא נגיש מקומית.** פופאפ Google + `.env.local` בלי מפתחות Firebase. מפתחות Firebase קיימים ב-Vercel **רק בסביבת Production** — `vercel env pull` ברירת מחדל מושך development, מחזיר כמעט כלום, **ודורס** מפתחות מקומיים.

**הדרך שעובדת לאימות UI:** עמוד רתמה זמני — client route עם `if (process.env.NODE_ENV === 'production') return null` שמרכיב את הרכיב האמיתי בלי אימות. למחוק לפני קומיט.

**שלוש מלכודות שהופכות בדיקת דפדפן ל-false pass שקט:**
1. פופאפ לידים ב-`components/layout/ConditionalFooter.tsx:96` מרנדר `fixed inset-0 z-[9999]` **4 שניות אחרי טעינה** ואוכל כל אינטראקציה עם קנבס
2. Chromium headless מקבע rAF ל-30fps — כל מדידת ביצועים חסרת משמעות בלי `--disable-gpu-vsync --disable-frame-rate-limit`
3. `page.evaluate(fn)` נשבר תחת `tsx`

**אין deploy אוטומטי מ-git** — דחיפה ל-GitHub לא מעלה כלום. חייבים `vercel --prod --yes`.

**חוקי אבטחה מחייבים** (`CLAUDE.md`): `https` בלבד · הפניות חיצוניות רק דרך `isAuthorizedRedirect()` עם דומיין ברשימת ההיתר · קלט משתמש במיילים דרך `escapeHtml()` · סקריפט חיצוני חדש מחייב עדכון CSP ב-`next.config.js`.

**Firestore לא מוגדר עם `ignoreUndefinedProperties`** — כתיבת שדה `undefined` **זורקת**. לכתוב שדות אופציונליים בספרד מותנה.
